# Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
Git ветка - указатель на коммит, а в SVN - клон дирректории
# Можно ли в SVN сделать коммит без интернета? Почему?
Нет, коммит сразу отправляется в репозиторий на сервере, локально хранится только копия без истории
# В каких сценариях SVN до сих пор может быть предпочтительнее Git?
в случаях legacy-проектов(в гос секторе и банкингах)
