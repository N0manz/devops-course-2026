# Практическая работа 6 Веб-сервер и автоматизация доставки

## Результат
Статический сайт размещается через Nginx по HTTPS. Запросы к HTTP перенаправляются на HTTPS, а пользовательские файлы доставляются отдельным сценарием `scripts/deploy.sh`.

## TLS и безопасная конфигурация
Для HTTPS используется самоподписанный сертификат с SAN. Закрытый ключ хранится только на сервере с ограниченным доступом и не добавляется в репозиторий. Перед применением изменений нужно проверить конфигурацию Nginx и выполнить безопасную перезагрузку службы.

## Доставка
Сценарий проверяет наличие главной страницы и чистое состояние Git, поддерживает пробный запуск `--dry-run`, передаёт содержимое через rsync и проверяет HTTPS-ответ. Перед запуском задаются параметры целевого сервера, каталога, URL и сертификата через переменные окружения. Это позволяет использовать сценарий без публикации адресов, учётных записей или путей конкретной машины.

## Проверки
`scripts/audit.sh` проверяет настройки SSH и межсетевого экрана, активность Nginx, синтаксис его конфигурации, срок сертификата, права каталога сайта и закрытого ключа. Переменные `TLS_CERTIFICATE`, `SITE_ROOT` и `TLS_KEY` задаются в окружении перед запуском.
